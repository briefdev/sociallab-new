# sociallab-new

موقع سوشل لاب الجديد — HTML/CSS/JS ثابت، بدون framework.

- الصفحات المولّدة: `index.html`، `features/*.html`، `integrations.html`، `case-studies.html`، `pricing.html`، `demo.html`، `faq.html`
- لتعديل المحتوى أو الهيدر/الفوتر: عدّل `_dev/build.py` أو `_dev/features.py` أو `_dev/partials.py` ثم شغّل:

```
python3 _dev/build.py
```

- كل النصوص والأرقام مصدرها `docs/content-inventory.md` (من موقع ومنصة سوشل لاب الحالية).
- ملخص التصميم: `design-brief.md`
